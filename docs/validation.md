# 検証の範囲

## 0.2.0の確認

公開前にPython 3.11の独立した環境へ `uv.lock` に従ってインストールし、47件のテストとRuffの静的検査に通りました。
テストでは接続された装置にコマンドを送りません。

| 対象 | 確認内容 |
| --- | --- |
| Ticの状態読み取り | シリアル番号の先頭の0、稼働時間、電圧、リミット、異常一覧 |
| エラーなしの表示 | `None` を文字ごとの異常へ分割しない。実際の `Low VIN` などは残す |
| 移動 | 原点復帰、上下端の移動、通常終了で下端かつ無励磁 |
| 異常時 | 両リミットの作動、移動異常、期限超過、中断で位置記録を無効化 |
| 位置記録 | 別機体、再起動、ストローク変更、位置カウンター変更、不確かさの変更を検出 |
| 明示的な原点復帰 | `home` は保存済みの下端位置でも原点復帰を実行 |
| 初期値 | 68 mm、最大速度150000000。旧50 mmは明示的に選択可能 |
| 実験サンプル | USBなしの2往復、終了時の下端確認、移動異常後の自動復帰を抑止 |

GitHub ActionsはmacOS、Windows、Linuxでインストール、テスト、静的検査、サンプル実行、パッケージのビルドを行います。
各コミットの実行結果は [Actions](https://github.com/dainakai/plate-lift-control/actions/workflows/test.yml) で確認できます。
CIは実際のTic用ドライバーやUSB接続を検証しません。

## 実機の確認

装置がPololuの公式アプリで正しく動作することは、装置の使用者から2026年9月12日に報告されています。
公式アプリでの速度150000000、電源入力電流約0.27 Aという使用結果も、既定速度を決める際の参考にしています。
電流値はモーター各相の電流制限とは別です。

公開版のスクリプトでMacとWindowsの実機USB操作を完了したという検証結果は、まだありません。
READMEの初回操作に従って、原点復帰、上下の向き、リミット位置、停止後の保持を現物で確認してください。

## 制約

- ソフトは上下端のスイッチとTicの位置カウンターを使います。物理的な絶対位置やガラスの保持力は測定しません。
- 手回しや無通電時のずれは検出できません。公式アプリや手回しで動かしたあとも `home` を行います。
- モーター停止後は無励磁にします。無通電で保持できる機構を前提としています。
- 2個のNCスイッチを前提としますが、個々の断線と実際のリミット作動を電気的に区別することはできません。
- 撮影サンプルのカメラ処理は表示のみです。実際に取得する処理へ置き換える必要があります。
