# BIZ UDPゴシック

取扱説明スライドとPDFの日本語本文に、Google Fonts版のBIZ UDPゴシックを使う。

- `BIZUDPGothic-Regular.ttf`: 標準。
- `BIZUDPGothic-Bold.ttf`: 太字。
- `OFL-BIZUDPGothic.txt`: SIL Open Font License 1.1。

配布元は[Google FontsのBIZ UDPGothicディレクトリ](https://github.com/google/fonts/tree/main/ofl/bizudpgothic)である。
Mac・WindowsでPPTXを編集する場合は、標準・太字の2個のTTFを先にインストールする。
PDFには書体が埋め込まれているため、閲覧側でのインストールは不要である。
